# Excel Sales Analytics Dashboard

## Project Overview

This project is a complete Excel-based Sales Analytics Dashboard designed to analyze business performance, customer orders, product trends, and operational insights using real-world business data.

The goal of this project was to practice and demonstrate practical business analytics skills used in data-driven companies for reporting, operational monitoring, and decision-making.

The project focuses on transforming raw sales data into meaningful insights using Excel analytics tools such as Pivot Tables, KPI dashboards, charts, and data visualization.

---

# Business Problem

Businesses generate large amounts of transactional data every day. Without proper analysis, it becomes difficult to:

* Track sales performance
* Identify profitable regions
* Understand customer purchasing behavior
* Monitor operational efficiency
* Support management decision-making

This project solves these challenges by creating an interactive reporting dashboard inside Microsoft Excel.
