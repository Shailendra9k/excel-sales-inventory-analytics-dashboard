Excel Sales Analytics Project
Project Overview
This project is an Excel-based Sales Analytics Dashboard created to analyze customer orders, product performance, sales trends, and regional business insights.
The project demonstrates practical Excel analytics skills including:
Data cleaning
Pivot Tables
Dashboard creation
KPI tracking
Business reporting
Data visualization
This project is highly relevant for Data Analyst, Business Analyst, and Operations Analytics roles.
